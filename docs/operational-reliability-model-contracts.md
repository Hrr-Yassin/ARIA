## Confirmed defects in this program

1. Observation-complete loop entry skipped evidence review. Two focused tests failed before correction; shared finalization fixes both paths.
2. Final authorized operation exhausted step count and prevented processing on recovery. Finalization now runs before the dispatch budget check; no extra dispatch is allowed.
3. Pause during review still allowed completion. Stop checks after awaited finalization preserve pending processing and completed evidence.
4. Missing native usage was fabricated as zero or a partial total; strings/booleans/negative components could be coerced. Seven invalid-count cases and one truncated case failed before correction (3 test methods, 8 subtest failures). Native usage now requires both nonnegative strict integer counts. Local inference cost remains known zero; hosted missing charges are not inferred as zero.
